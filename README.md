# 流 · 丝线 (Flowing Silk)

一段纯 Canvas 2D 的「流动丝线」动画：无数细线跟着看不见的风流动，
表达思绪、情绪在流、慢慢平静下来。

单文件、零依赖、零构建。双击 `index.html` 即可在浏览器里跑。

---

## 效果

- 深暮渐变背景（靛紫 → 暗紫 `#0e1326 → #171225`），不是纯黑虚空。
- 820 根丝线在多层正弦叠加的「风场」里同向飘动，像风掠过。
- 颜色偏柔：淡薰衣草 / 淡青 / 极少淡玫瑰（一点温度，不是火星色）。
- 开场 18 秒内由略动缓降至平静，之后呼吸般轻浮。
- 鼠标移上去会柔和排开丝线。
- 底部诗句淡入淡出：`思绪如丝 · 随风而流 · 终归于静`

## 运行

```bash
# 方式一：直接打开
双击 index.html

# 方式二：起个本地服务（推荐，避免某些浏览器限制）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 技术说明

- 纯 **Canvas 2D**，无任何第三方库。
- 用 `mulberry32` 带种子伪随机（`20261104`），画面可复现。
- 每帧用半透明暮色覆盖上一帧，留下丝线残影，形成「流」的拖尾。
- `devicePixelRatio` 上限 2，兼顾高分屏清晰度和性能。
